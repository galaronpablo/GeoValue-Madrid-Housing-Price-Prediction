## 📌 Project Overview

**GeoValue Madrid** is a group project focused on the **automatic valuation of residential properties in Madrid** using **Machine Learning and spatial statistical methods**.

We worked through the complete analytical process: data cleaning, exploratory analysis, spatial data processing, predictive modeling, model comparison and the development of an interactive **R Shiny** application for housing price estimation.

The central question was whether incorporating geographical information and spatial relationships could improve housing price predictions.

## 🛠️ What We Did

### 1. Data Cleaning & Exploratory Analysis

- Explored the housing dataset and identified missing values, outliers and inconsistencies.
- Applied **MICE** for missing-data imputation.
- Updated historical housing prices and applied a **log transformation** to the target variable.
- Removed observations located in non-residential areas and geographically isolated properties.
- Investigated relationships between housing characteristics, neighborhood variables and prices.

### 2. Spatial Analysis

- Investigated **spatial dependence** in Madrid housing prices.
- Defined spatial neighborhoods and spatial weight matrices based on property distances.
- Incorporated spatial information into the modeling process.
- Explored spatial modeling and geostatistical approaches, including **Kriging** and the **Spatial Error Model (SEM)**.

### 3. Machine Learning & Predictive Modeling

Compared a range of predictive models:

- Linear Regression
- Random Forest
- XGBoost
- K-Nearest Neighbors (KNN)
- Support Vector Regression (SVR)
- Neural Networks
- Ordinary Kriging
- Random Forest + Residual Kriging
- Spatial Error Model (SEM)

We used **RMSE, MAE and R²** to compare predictive performance and assess the contribution of spatial information.

### 4. Interactive App: GeoValue Madrid

Developed an **R Shiny** application that allows users to:

- Select a location in Madrid using an interactive map.
- Enter property characteristics such as floor area, age, type and amenities.
- Obtain model-based estimates of housing prices.
- Compare predictions generated by different modeling approaches.
- Explore geographical context and nearby observations.

## 🇪🇸 Descripción del Proyecto

**GeoValue Madrid** es un proyecto grupal de **valoración automática de viviendas en Madrid** mediante modelos predictivos, técnicas de Machine Learning y estadística espacial.

El objetivo fue estudiar los factores asociados al precio de las viviendas y comprobar cómo influye la información geográfica en la capacidad predictiva de diferentes modelos.

### 🛠️ Qué hicimos

- **Depuración y exploración:** Tratamiento de valores ausentes con MICE, análisis de atípicos, transformación de precios y limpieza espacial de registros.
- **Análisis espacial:** Estudio de relaciones geográficas entre viviendas y construcción de matrices de pesos espaciales.
- **Modelización predictiva:** Comparación de regresión lineal, Random Forest, XGBoost, KNN, SVR y redes neuronales.
- **Métodos espaciales:** Evaluación de Kriging, Random Forest con Kriging de residuos y modelos de error espacial.
- **Evaluación de modelos:** Comparación mediante RMSE, MAE y R².
- **Puesta en producción:** Desarrollo de **GeoValue Madrid**, una aplicación interactiva con R Shiny para obtener estimaciones del precio de viviendas.
