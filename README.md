### 📌 Project Overview

**GeoValue Madrid** is a group project focused on the **automatic valuation of residential properties in Madrid** using **Machine Learning and spatial statistical methods**.

We worked through the complete analytical process: data cleaning, exploratory analysis, spatial data processing, predictive modeling, model comparison and the development of an interactive **R Shiny** application for housing price estimation.

The central question was whether incorporating geographical information and spatial relationships could improve housing price predictions.

### 🛠️ What We Did

#### 1. Data Cleaning & Exploratory Analysis

- Explored the housing dataset and identified missing values, outliers and inconsistencies.
- Applied **MICE** for missing-data imputation.
- Updated historical housing prices and applied a **log transformation** to the target variable.
- Removed observations located in non-residential areas and geographically isolated properties.
- Investigated relationships between housing characteristics, neighborhood variables and prices.

#### 2. Spatial Analysis

- Investigated **spatial dependence** in Madrid housing prices.
- Defined spatial neighborhoods and spatial weight matrices based on property distances.
- Incorporated spatial information into the modeling process.
- Explored spatial modeling and geostatistical approaches, including **Kriging** and the **Spatial Error Model (SEM)**.

#### 3. Machine Learning & Predictive Modeling

Compared a range of predictive models:

- Linear Regression
- Random Forest
- XGBoost
- K-Nearest Neighbors (KNN)
- Support Vector Regression (SVR)
- Neural Networks
- Ordinary Kriging
- Random Forest + Residual Kriging
- Spatial Error Model (SEM)

We used **RMSE, MAE and R²** to compare predictive performance and assess the contribution of spatial information.

#### 4. Interactive App: GeoValue Madrid

Developed an **R Shiny** application that allows users to:

- Select a location in Madrid using an interactive map.
- Enter property characteristics such as floor area, age, type and amenities.
- Obtain model-based estimates of housing prices.
- Compare predictions generated by different modeling approaches.
- Explore geographical context and nearby observations.

**🚀 [Try the GeoValue Madrid App](https://geovaluemadrid.shinyapps.io/geovalue_madrid/)**

### 📌 Descripción del Proyecto

**GeoValue Madrid** es un proyecto grupal centrado en la **valoración automática de viviendas residenciales en Madrid** mediante **Machine Learning y métodos de estadística espacial**.

Desarrollamos el proceso analítico completo: depuración de datos, análisis exploratorio, procesamiento de datos espaciales, modelización predictiva, comparación de modelos y desarrollo de una aplicación interactiva con **R Shiny** para estimar precios de viviendas.

La pregunta central fue si incorporar información geográfica y relaciones espaciales podía mejorar las predicciones de los precios de las viviendas.

### 🛠️ Qué hicimos

#### 1. Depuración y Análisis Exploratorio de Datos

- Exploramos el conjunto de datos de viviendas e identificamos valores ausentes, atípicos e inconsistencias.
- Aplicamos **MICE** para la imputación de datos ausentes.
- Actualizamos precios históricos de viviendas y aplicamos una **transformación logarítmica** a la variable objetivo.
- Eliminamos observaciones ubicadas en zonas no residenciales y viviendas geográficamente aisladas.
- Investigamos las relaciones entre características de las viviendas, variables del entorno y precios.

#### 2. Análisis Espacial

- Investigamos la **dependencia espacial** en los precios de las viviendas de Madrid.
- Definimos vecindades espaciales y matrices de pesos espaciales basadas en las distancias entre viviendas.
- Incorporamos información espacial al proceso de modelización.
- Exploramos enfoques de modelización espacial y geoestadística, incluidos **Kriging** y el **Modelo de Error Espacial (SEM)**.

#### 3. Machine Learning y Modelización Predictiva

Comparamos diversos modelos predictivos:

- Regresión lineal
- Random Forest
- XGBoost
- K vecinos más cercanos (KNN)
- Regresión con máquinas de vectores de soporte (SVR)
- Redes neuronales
- Kriging ordinario
- Random Forest + Kriging de residuos
- Modelo de Error Espacial (SEM)

Utilizamos **RMSE, MAE y R²** para comparar el rendimiento predictivo y evaluar la contribución de la información espacial.

#### 4. Aplicación Interactiva: GeoValue Madrid

Desarrollamos una aplicación con **R Shiny** que permite:

- Seleccionar una ubicación en Madrid mediante un mapa interactivo.
- Introducir características de la vivienda, como superficie, antigüedad, tipo y equipamiento.
- Obtener estimaciones de precios de viviendas basadas en los modelos.
- Comparar predicciones generadas por distintos enfoques de modelización.
- Explorar el contexto geográfico y las observaciones cercanas.

**🚀 [Probar la aplicación GeoValue Madrid](https://geovaluemadrid.shinyapps.io/geovalue_madrid/)**
